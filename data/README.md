# Data

Download the two files of the folder **`Raw Data Device 1 (1M KCl, +-1V)`** from figshare
([doi:10.6084/m9.figshare.33269229](https://doi.org/10.6084/m9.figshare.33269229)) and place them here:

```
241201_123908_1M_KCl_1V_0.1hz_4_1000H_1000W_N401_iv.csv    electrokinetic recording (1.5 MB)
241201_123908_1M_KCl_1V_0.1hz_4_1000H_1000W_N401_img.tif   reflectance image stack (0.8 GB)
```

Files in this folder are not tracked by git.
